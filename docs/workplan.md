## WP-152 — Подключение к старому диалогу и восстановление истории v9

Статус: **проверено локально, production rollout pending**.
Backlog: `BL-FIX-079`. Дефекты: `BUG-148`–`BUG-151`.

1. Исключить устройства с истёкшими сессиями из согласования состава и отправки.
   Подтверждённое устройство может заменить резервацию координатора, который
   ещё не подтвердил свой Welcome. Обработать сохранённый Welcome во время
   ожидания нового состава.
2. Отбирать для новых операций пакеты, которые сервер получил менее 83 дней назад.
   В v10 принимать подписанное дерево с историческим листом. Проверять срок
   пакета в новых Add.
3. Восстанавливать архив только после подтверждённой расшифровки на текущем
   устройстве. Перепроверять доступность уже открытых сообщений при готовности MLS.
4. Проверить серверные и frontend regressions, v9/v10 на release WASM и production
   workflow. После обновления проверить HTTP, состояние диалога и Welcome ACK.

Готовность: проверки проходят, production отдаёт v10. Получение новых сообщений
и двусторонний перенос на физических устройствах проверяются после обновления
клиентов. Восстановление данных без сохранившихся ключей вне scope.
